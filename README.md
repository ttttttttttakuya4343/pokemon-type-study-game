# タイプ！タッチ！

ひらがな・カタカナが読める5歳ごろから遊べる、ポケモンのタイプ相性学習ゲームです。

## 起動

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーを使う場合:

```sh
python3 -m http.server 4173
```

その後 `http://localhost:4173` を開いてください。

## 学習設計

- 「ゆっくり れんしゅう」: 時間制限なし・ヒントあり。10問・15問・20問から選択
- 「3びょう バトル」: 3.5秒以内に選ぶ10問（瞬時の判断を練習）
- 「チーム バトル」: あいてを見て、てもちの3匹から相性のよいポケモンを選ぶ10問
- 「タイプ ずかん」: 防御側のタイプから、ばつぐんになる攻撃タイプを確認
- 問題文の読み上げ、正誤音、3択の大きなボタンに対応
- 成績はブラウザに保存
- 1回のゲーム内では同じポケモンを出題しない
- 間違えたポケモンは次回のゲームで優先的に復習

相性判定は添付PDFの18タイプ表（ばつぐん・いまひとつ・こうかなし）に対応しています。

## ポケモン画像

登場する50匹の画像は、公式ポケモンずかんの画像URLリストから取得します。

```sh
sh scripts/download-pokemon-images.sh
```

画像・ポケモン名などの権利は各権利者に帰属します。個人利用を想定しています。
